Comparison of divergence algorithms

2026-01-23 Views

I have seen two common algorithms for calculating divergence from wind.
One is from Windspharm:

another is from Metpy.

I also tried to calculate it myself.

(It worth to mention why /4 is important there. We do that since u.differentiate will have the results with the unit in 1/deg, but out dx is calculated to have the unit in meters/0.25 degrees, so /4 is required to complete the conversion)

For the sake of making the results comparable to each other and have a good referee, I, again, use the ERA5 data from the data store, and I am treating the divergence data from the dataset as the referee. I guess I have a faith on the ERA5 maintainers… By the way, the divergence variable from the dataset should be used as dataset.d (instead of dataset.divergence, and I wonder if this is a result a laziness)…

Here are some results:

It appears like they are all similar in the midlatitudes, but metpy seems to have extreme values in the tropics, and both windspharm and my native method have issues in the polar region.
To make the difference more obvious, I made the plot below to compare the results from different methods. Please note the upper-left one is the reference plots, so it is not a result of subtraction.

It seems like the midlatitudes are vary similar across all 4 subplots, is that true?
To answer that, I draw another bar plot to compare the average difference in the midlatitudes.

Windspharm looks like having the best performence among the three. However, using any of them are okay, as the averaged difference is just 1/1000 of the original magnitude of the diveregence values (1x10^-5).

Also, the typical ERA5 dataset is quaterly gridded, and sometimes people (including myself) don’t really want to have the resolution as fine as this level. So I also tried a more crude resolution (every degree).




Wow! Windspharm is not outstanding this time! And we can easily see that all the methods have more disagreements with the reference values as the resolution goes poorer.

In terms of conclusion? I cannot think about any, but we probably should recommand people to use the ERA5 data directly if possible. I probably should write more about the algorithm behind each method, but I don’t have that much energy to do that at this moment. Let here be the end then.
